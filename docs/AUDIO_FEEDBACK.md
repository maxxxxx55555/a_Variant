# Marchland Oaths — audio feedback

Exploration/settlement/combat/war remain four separate compositions. Weapons and five footstep materials use spatial SFX; alchemy, equipment, town trade, recruitment, diplomacy, buildings and equipment crafting retain their actual contextual cues. Rejected alchemy/council/construction/crafting/trade paths now use ui_error.

All generated BaseButton controls are registered once, after their own action handlers. The interface adapter snapshots playback at button-down and supplies a fallback click only if that action did not already produce a cue; the acknowledgment survives a departing control. Focus/selection/range adjustments use the independent UI bus and a restrained focus rate limit. Cosmetic pitch changes do not consume gameplay RNG. Native disabled controls do not activate; defensive handlers still report failed stale requests. The generic adapter is deliberately shared interface instrumentation maintained as separate source files; no cross-game assets, names, paths or simulation are copied.

Tests: test_ui_audio_feedback.gd reproduces formerly silent controls, focus, contextual deduplication, destroyed-node acknowledgment, pitch limits, RNG isolation and forced mute. test_context_audio.gd exercises real rejected game actions. test_audio.gd, test_music_transitions.gd, test_audio_assets.py and test_soundtrack.py verify bus gains, persisted settings, crossfades, distinct assets, loop envelopes and source hashes. QA is inaudible by GAME_AUDIO_MUTED=1. Short headless tests stop/clear their audio and allow the mixer to settle before exit; ordinary gameplay ownership remains unchanged.

Inherited audio license text is retained byte-for-byte in Git. Original music provenance is retained; the two new profile-specific synthesized cues are covered by the existing CC0 sound-effect dedication and interface-provenance.json. No claim of a human performance is made. Full F4 bilingual suite evidence is stored externally; final export testing remains F7.
