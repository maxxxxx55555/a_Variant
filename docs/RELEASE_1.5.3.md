# Marchland Oaths 1.5.3 — release candidate

A restrained frame now backs the health and stamina meters, improving contrast against bright weather and terrain. Gameplay, saves, music and asset licensing are unchanged.

This candidate is not a release until fresh bilingual tests, export and native checks, full seeded routes, legacy compatibility, gallery review, measured stability, exact-head CI and artifact checks pass. Existing 1.5.2 release assets remain unchanged. Windows x64 only; owner play and listening checks remain required before announcement.

## Русский

Для полос здоровья и выносливости добавлена подложка, чтобы они оставались читаемыми на светлом фоне. Игровые правила, сохранения и музыка не менялись. Публикация возможна только после полного повторного тестирования.
