# Marchland Oaths 1.5.1

## English

Iron-mode death is terminal across repeated hits, callbacks, resume, reload and live locale changes; ordinary paid recovery remains available. Complete campaign precision, exploration boundaries, companion lifetime and paused squad behavior have named regressions.

Four distinct background moods and two musical finales, actual Gemini/Lyria provenance, independent Master/Music/SFX/UI controls, curated illustrations and licensed fonts, reduced motion, loading tips and credits. Original licenses and provenance are retained byte for byte. The release is Windows x86_64, built with Godot4.7 Stable using its compatibility renderer.

Download `MarchlandOaths-Windows-1.5.1.zip`, extract the whole archive and run `MarchlandOaths.exe`. Keep the supplied data pack, README and license folders together. Verify the ZIP against the separately supplied SHA256SUMS file. Sources open in Godot4.7; private encrypted export keys and templates are not public source dependencies for editor play.

Save compatibility: protected1.4.0 and1.5.0 profiles load with progress intact; original installation keys and legacy folder names are unchanged.
Back up the entire closed-game profile before upgrading; include its local key and guard files. Iron-mode death intentionally prevents backup rollback.

Release hardening includes signed bounded saves, exact finite numeric metadata, atomic writes, authenticated known-good recovery, critical-data manifest and compiled trusted fallback, read-only integrity safe mode and encrypted public packs. Public executables physically omit the verifier and reject QA arguments. Private QA requires a compiled feature and `GAME_QA=1`; it is not distributed.

Acceptance: Terminal iron-mode death rejects repeated callbacks, loading and recovery; normal death retains paid recovery. Protected1.4.0 and1.5.0 profiles preserve progress and installation keys. All49 GDScript warning categories are enforced on90 shipping/private-QA scripts. 62 rendered Godot invocations passed in each locale, plus Python byte/export/isolation/audio contracts. 50 complete seeded campaigns, a2628.797-second normal rendered soak and three exact native complete campaigns passed. The measured rainy scene ran at59.98 FPS (60 cap),5522ms load,340 draw calls at1280×720 on the tested AMD integrated GPU.

Full logs, raw seeded/soak results, real-engine galleries and exact public/private pack digests are in the release evidence. Both source locales and native routes report no unexpected errors. Negative/rejected diagnostic runs remain separately labelled. Historical Windows audio-device invalidation was reproduced/recorded separately; three retries passed and final quiet suites used Dummy audio, while audio assets/routing were checked by dedicated tests.

Limits: this is a stylized offline indie game, not an AAA-scale production. Automated tests on one host are not an independent human playtest or universal hardware certification. Offline integrity and encryption do not prevent a device owner from patching code or extracting local keys. The portable executable is not Authenticode signed. The existing1.5.0 tag and assets are immutable; this patch uses1.5.1. Android artifacts are omitted in this cycle because the emulator cannot boot on the host. No Android runtime PASS is claimed. Edition exclusions are explicitly listed in README and the promise matrix.

Железная смерть окончательна: повторные удары, колбэки, загрузка и продолжение не оживляют героя. Обычное платное восстановление сохранено. Исправлены точность сохранений, границы наград за исследование, время жизни спутников и пауза отрядов.
