# Assets Directory
Oaths of the March / «Клятвы Пограничья»

All runtime audio and procedural visual feedback are managed by Godot code singletons (`AudioManager.gd`, `WorldEnvironment`, and GDScript Mesh Generation) to maintain the target compact build size budget (≤ 700 MB, target 300–500 MB).

Subdirectories for custom high-poly or texture packs:
- `models/`
- `textures/`
- `audio/`
- `fonts/`
